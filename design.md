Разработка схем экранов и интерфейса
Экран 1: Экран выбора аватара:
Список доступных аватаров.
Кнопка "Выбрать аватар", подтверждающая выбор.
Экран 2: Главный экран (прогресс пользователя):
Аватар пользователя в верхней части экрана.
Отображение текущих рабочих весов для каждого упражнения/тренажера.
Кнопка "Редактировать веса" (активируется, если подтверждено местоположение).
Графики и статистика прогресса по дням/неделям.
Экран 3: Редактирование рабочих весов:
Список упражнений и тренажеров.
Поля для ввода/редактирования рабочих весов.
Кнопка "Сохранить изменения" (доступна только после подтверждения через API).
Экран 4: Экран ошибок/статуса:
Сообщения о статусе подключения или ошибках.
Статус проверки местоположения через API.
Схема интерфейса:

С использованием UIKit реализовать взаимодействие с кнопками, текстовыми полями и изображениями.
Интерфейс должен быть простым и понятным, использовать стандартные компоненты iOS для отображения данных.


Проектирование структуры данных
Модели для CoreData:

User (Пользователь):

id: String
avatar: String
progress: [Progress] (связь с прогрессом)
currentWeights: [Weight] (связь с рабочими весами)
Progress (Прогресс):

id: String
date: Date
points: Int
avatarGrowth: Float (изменение аватара в зависимости от баллов)
Weight (Рабочий вес):

id: String
exerciseId: String
weight: Float
updatedAt: Date
API Interaction (Взаимодействие с API):

Реализовать модель для хранения информации о статусе пользователя в клубе (например, через флаг isInClub).


API взаимодействие для получения данных о местоположении пользователя и баллах
Запросы API:

Проверка местоположения: API для получения статуса пользователя (находится ли он в клубе или нет).
Пример запроса: GET /user/location/status?userId={id}
Ответ: { "isInClub": true }
Получение прогресса пользователя: API для получения текущего прогресса и баллов.
Пример запроса: GET /user/progress?userId={id}
Ответ: { "points": 150, "avatarGrowth": 0.5 }
Обновление рабочих весов: API для редактирования рабочих весов.
Пример запроса: POST /user/weights/update
Тело запроса: { "userId": "{id}", "exerciseId": "{exerciseId}", "newWeight": 75.0 }
Ответ: { "status": "success" }
Интеграция с API:

Использование URLSession или сторонней библиотеки, например, Alamofire, для работы с запросами и получения данных.
Реализовать обработку ошибок и статуса запросов (например, если нет соединения с сервером).
