# CoachMe

CoachMe — приложение для геймификации тренировок в фитнес-клубах. Приложение отслеживает прогресс пользователей и позволяет им получать новый уровень в зависимости от достижений. Оно отображает и дает возможность редактировать рабочие веса в упражнениях и тренажерах, с доступом к редактированию только после подтверждения нахождения пользователя в клубе через API (проход через турникет). Перед выходом из зала пользователь должен получить подтверждение тренера о выполненных упражнениях. Награды от клуба стимулируют пользователей достигать новых уровней и продолжать тренировки.


> **Внимание**: проект находится на стадии разработки и может содержать баги или недоработанные функциональности.


## Функции:
- Регистрация и авторизация пользователя.
- Просмотр статистики тренировок и прогресса.
- Выбор и настройка аватара.
- Подтверждение нахождения в клубе для редактирования данных.

## Технологии:
- **UIKit** — для создания интерфейса приложения.
- **CoreData** — для локального хранения данных о пользователях и их прогрессе.
- **Combine** — для реактивного программирования и обработки асинхронных событий.
- **GCD** — для многозадачности.
- **MVVM** — архитектурный подход, разделяющий модель, представление и логику приложения.
