1. Экран выбора аватара
Цель: Пользователь выбирает свой аватар.

Компоненты:
Список аватаров (можно отобразить их как карточки или изображения в сетке).
Кнопка "Выбрать" для подтверждения выбора.
Описание или подсказки о том, как выбор аватара влияет на прогресс.
UI элементы:

UIImageView для отображения каждого аватара.
UIButton для выбора аватара.
UICollectionView для отображения списка аватаров в виде сетки.
Пример интерфейса:

Заголовок: "Выбери свой аватар"
Сетка с аватарами.
Кнопка "Выбрать" под сеткой.
2. Главный экран (прогресс пользователя)
Цель: Показывает текущий прогресс пользователя (рабочие веса, аватар и т.д.).

Компоненты:
Аватар пользователя, который будет отображаться и изменяться в зависимости от прогресса.
Список с рабочими весами для каждого упражнения/тренажера.
Статистика с графиками (прогресс по времени или баллам).
Кнопка "Редактировать" для изменения рабочих весов (активируется только если пользователь находится в клубе).
Статус пользователя (находится ли он в клубе, через API).
UI элементы:

UIImageView для отображения аватара.
UILabel для отображения статистики (баллы, рост аватара).
UITableView для отображения рабочих весов.
UIButton для редактирования.
UILabel для статуса пользователя (находится ли он в клубе).
Пример интерфейса:

Заголовок: "Твой прогресс"
Аватар пользователя в верхней части экрана.
Список с упражнениями и их рабочими весами.
График прогресса.
Кнопка "Редактировать" (доступна, если подтверждено местоположение).
3. Экран редактирования рабочих весов
Цель: Пользователь может редактировать свои рабочие веса для различных упражнений.

Компоненты:
Список упражнений с текущими рабочими весами.
Поля для ввода/редактирования значений весов.
Кнопка "Сохранить изменения", которая будет активна только если подтверждено местоположение пользователя (прохождение через турникет).
Подтверждение изменений (можно сделать с помощью попапа или модального окна).
UI элементы:

UITextField для ввода рабочего веса.
UITableView для списка упражнений.
UIButton для сохранения изменений.
UIAlertController для подтверждения сохранения.
Пример интерфейса:

Заголовок: "Редактирование рабочих весов"
Список упражнений и текущих весов.
Поля ввода для каждого упражнения.
Кнопка "Сохранить".
4. Экран подтверждения тренером
Цель: Пользователь должен получить подтверждение тренера для сохранения изменений.

Компоненты:
Модальное окно с запросом подтверждения тренера.
Кнопка "Подтвердить" для тренера, которая активирует обновление данных.
Текстовое сообщение о необходимости подтверждения.
UI элементы:

UIAlertController с запросом подтверждения.
UIButton для подтверждения.
Пример интерфейса:

Заголовок: "Подтвердите выполнение упражнений"
Сообщение: "Пожалуйста, подтвердите изменения весов и выполнения упражнений."
Кнопка "Подтвердить" для тренера.
5. Экран ошибок/статуса
Цель: Отображает статус подключения и сообщения об ошибках.

Компоненты:
Сообщение о состоянии сети, ошибках API.
Возможность попробовать еще раз выполнить операцию.
UI элементы:

UILabel для отображения сообщений об ошибках.
UIButton для повторного запроса или обновления данных.
Пример интерфейса:

Заголовок: "Ошибка"
Сообщение: "Не удалось подключиться к серверу. Попробуйте снова."
Кнопка "Попробовать снова".
6. Экран статистики (по желанию)
Цель: Отображает более подробную информацию о прогрессе пользователя в виде графиков и статистики.

Компоненты:
Графики с трендами прогресса.
Исторические данные (например, баллы по месяцам).
Возможность фильтровать статистику по времени (день, неделя, месяц).
UI элементы:

Charts для отображения графиков (с использованием сторонних библиотек, например, Charts).
UITableView или UICollectionView для списка статистики.
Пример интерфейса:

Заголовок: "Статистика"
Графики прогресса.
Список с историей баллов и результатов.
Общие принципы дизайна:
Чистота и минимализм: Ориентируемся на минималистичный дизайн, как в стандартных приложениях Apple.
Интуитивно понятный интерфейс: Все кнопки и действия должны быть очевидными.
Адаптивность: Интерфейс должен быть адаптирован для разных размеров экрана (iPhone, iPad).
