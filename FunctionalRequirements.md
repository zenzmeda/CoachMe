1. Функциональные требования
Основные функции приложения:

Выбор аватара: Пользователь должен иметь возможность выбрать аватар для себя из доступных вариантов.
Отображение прогресса: Приложение должно показывать текущий прогресс пользователя по различным упражнениям и тренажерам.
Редактирование рабочих весов и выполнения упражнений:
Пользователь может редактировать рабочие веса и выполнение упражнений в приложении.
Однако перед выходом из клуба пользователь должен подойти к тренеру и запросить подтверждение выполненных упражнений.
После подтверждения тренером данные о выполненных упражнениях и измененные веса будут синхронизированы в приложении.
Авторизация через API: Приложение должно проверять, находится ли пользователь в фитнес-клубе, через API (например, через турникет).
Обновление аватара: Аватар пользователя должен изменяться в зависимости от прогресса (например, рост аватара, изменение внешнего вида).
История изменений: Приложение должно хранить историю изменений рабочих весов и прогресса.
Подтверждение местоположения: Приложение должно проверять местоположение пользователя (прохождение через турникет) через API, прежде чем разрешить редактирование данных.

Дополнительные функции:

Уведомления: Уведомления о новых тренировках, обновлениях баллов и прогресса.
Просмотр статистики: Статистика прогресса по дням, месяцам, категориям упражнений.
Поддержка нескольких устройств: Возможность синхронизации данных между различными устройствами через облако (например, с использованием iCloud).

2. Нефункциональные требования
Производительность: Приложение должно быстро отображать прогресс, минимизируя задержки в UI, даже при большом количестве данных.
Надежность: Обработка ошибок (например, сбои в сети или проблемы с API) должна быть корректной, чтобы приложение продолжало работать.
Безопасность: Защита личных данных пользователя, включая историю тренировок и данные о местоположении.
Масштабируемость: Приложение должно быть готово к добавлению новых фитнес-клубов, тренировок и аватаров без значительных изменений в архитектуре.
Юзабилити: Удобный и интуитивно понятный интерфейс, адаптированный для разных устройств (iPhone, iPad).
